# راهنمای انتشار اپ آنامیس روی گیت‌هاب (نسخه تست)

## فایل‌های این بسته
همه را بدون پوشه، کنار هم آپلود کن:

- `index.html` (خود اپ)
- `manifest.webmanifest` (مشخصات نصب روی گوشی)
- `sw.js` (کار کردن بدون اینترنت و آپدیت)
- `icon-192.png`، `icon-512.png`، `icon-maskable-512.png`، `apple-touch-icon.png`، `favicon-32.png` (آیکون‌ها از لوگوی آنامیس)

## ۱. ساخت مخزن (Repository)
1. در github.com وارد حساب خودت شو (اگر نداری، رایگان بساز).
2. بالا سمت راست روی **+** و بعد **New repository** بزن.
3. نام مخزن را انگلیسی و ساده بگذار، مثلاً `anamis-app`.
4. گزینه **Public** را انتخاب کن (برای Pages رایگان لازم است) و **Create repository** را بزن.

## ۲. آپلود فایل‌ها
1. در صفحه مخزن روی **uploading an existing file** (یا Add file ← Upload files) بزن.
2. هر هشت فایل را انتخاب یا بکشید و رها کن.
3. پایین صفحه **Commit changes** را بزن.

## ۳. روشن کردن Pages
1. **Settings** ← **Pages** (منوی سمت چپ).
2. در Source گزینه **Deploy from a branch** را بگذار.
3. Branch را `main` و پوشه را `/ (root)` انتخاب کن و **Save** بزن.
4. بعد از یک تا دو دقیقه، آدرس اپ بالای همان صفحه ظاهر می‌شود:
   `https://نام-کاربری-تو.github.io/anamis-app/`

## ۴. نصب روی گوشی
- **اندروید (کروم):** باز کردن آدرس ← منوی سه‌نقطه ← **Install app** یا **Add to Home screen**
- **آیفون (سافاری):** باز کردن آدرس ← دکمه Share ← **Add to Home Screen**

بعد از نصب، اپ با آیکون لوگو و بدون نوار مرورگر باز می‌شود.

## ۵. آپدیت کردن اپ
1. هر وقت نسخه جدید `index.html` را از من گرفتی، در مخزن روی `index.html` بزن.
2. آیکون مداد (Edit) را بزن، همه متن را پاک و متن جدید را جایگزین کن، یا فایل جدید را با همان نام دوباره آپلود کن تا جایگزین شود.
3. **Commit changes** را بزن.
4. بعد از یک تا دو دقیقه، اپ را روی گوشی ببند و دوباره باز کن. اگر نسخه جدید نیامد، یک بار دیگر باز کن. نسخه جدید خودش جایگزین می‌شود.

## نکته‌های مهم
- **اطلاعات واقعی نگذار.** مخزن Public است و همه می‌توانند فایل‌ها را ببینند. مشتری واقعی، شماره تلفن، کلید پیامک یا رمز داخل آن نگذار.
- **داده‌ها فعلاً فقط در مرورگر همان گوشی ذخیره می‌شوند.** معامله‌ای که یک همکار ثبت می‌کند در گوشی ادمین دیده نمی‌شود. این بخش با سرور واقعی حل می‌شود. در این مرحله فقط ظاهر و منطق را تست کن.
- دکمه «نمای کاربر/ادمین» بالای اپ فقط برای تست است.
- گاهی دسترسی به گیت‌هاب در ایران ناپایدار است. قبل از دادن آدرس به همکارها با چند اینترنت مختلف (همراه و ADSL) امتحان کن.
